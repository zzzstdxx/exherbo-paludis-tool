# exherbo-paludis-tool
A Exherbo Linux tool written in C++

# Function:

``(1) Upgrade worldset`` (cave resolve world)
``(2) Sync repositories`` (cave sync)
``(3) Purge unneeded`` (cave purge)
``(4) Search packages`` (cave search ...)
``(5) Show package details`` (cave show)
``(6) Read unread repository news`` (eclectic news read new)
``(0) Exit`` (exit)
``Select an option:``
# Installation:
Install the file, then run ``gcc paludis.cpp -o paludis`` to compile it.
If you want you can copy it into ``/usr/bin/`` by doing ``doas cp paludis /usr/bin/`` to use it as a command
